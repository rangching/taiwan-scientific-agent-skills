# 翻譯規範（繁體中文，台灣用法）

## 原則

* 英文為主、繁中為輔；`description` 英文一字不改，繁中摘要放在 `metadata.description_zh`。
* **禁止 top-level 自創欄位**：規格只允許 name、description、license、compatibility、
  allowed-tools、metadata 六個，`skills-ref validate` 會擋下第七個。
* 技術名詞維持英文：function、API、model、prompt、dataset、pipeline、script。
* 台灣用詞：程式（非程序）、軟體（非軟件）、透過（非通過）、設定（非設置）、預設（非默認）、資料庫、伺服器。

## SKILL.md 雙語格式

```markdown
---
name: <原名，不可改>
description: <上游英文原文，一字不改>
license: <沿用上游>
metadata:
  version: "<沿用上游>"
  description_zh: "<一句繁中摘要，說明用途與觸發時機>"
  skill-author: <沿用上游>
  zh-tw-added: "2026-09-28"
  upstream: K-Dense-AI/scientific-agent-skills@<commit>
---

> 本 skill 衍生自上游 K-Dense Scientific Agent Skills（MIT），英文原文完整保留，
> 繁中導讀僅為使用輔助。

## 繁中導讀（zh-Hant-TW）

### 何時使用
<3–6 條繁中條列>

### 快速開始
<最短可跑流程，指令維持英文>

---

<以下為上游英文原文，一字不改>
```

> `version` 必須是 `metadata` 下第一個鍵：部分上游測試會斷言
> `metadata:\n  version:` 字面相鄰，順序一動就會紅燈。

## 不可翻譯清單

* 目錄名、frontmatter `name`、`scripts/` 檔名、函式名、變數名、CLI 參數。
* 授權文字、引用文獻（DOI、arXiv 編號）。

## 行數上限

* `SKILL.md` 不得超過 500 行（`tests/_meta` 強制檢查）。加上導讀後若超標，
  該 skill 改用精簡單行導讀，並省略 `zh-tw-added`／`upstream` 選填欄：
  `> 繁中導讀：<摘要>詳見下方英文原文。（衍生自上游 K-Dense Scientific Agent Skills，MIT 授權，原文完整保留。）`
