# 上游同步手冊

上游：https://github.com/K-Dense-AI/scientific-agent-skills（166 skills，更新頻繁）

## 設定

```bash
git remote add upstream https://github.com/K-Dense-AI/scientific-agent-skills.git
git fetch upstream
```

## 每月同步流程

1. `git fetch upstream && git log HEAD..upstream/main --oneline -- skills/ | head -n 50`
2. 對已移植的 skills：以英文段為準合併，繁中導讀若對應段落有變，加 `> 待更新` 標記。
3. 新 skills：排入下一批次，不在此次合併。
4. 跑 `python3 scripts/check_structure.py`，確認通過後再推版。

## 版本號

* `plugin.json` version 為本庫版本（0.1.0 起），不等於上游版本。
* 各 skill `metadata.version` 沿用上游，不自行重編。
