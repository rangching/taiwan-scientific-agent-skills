# 中文文獻檢索 Taiwan Scholar Search

> 檢索流程導引。各資料庫授權、館際合作、校外連線方式以各校圖書館公告為準。

## 繁中導讀 Zh-Hant Guide

### 何時使用

- 需要中文期刊、學位論文、專書、研究報告，英文資料庫找不到時。
- 寫中文文獻回顧、確認國內研究現況時。

### 快速開始

1. 先用關鍵字＋同義詞各查中英文一輪，避免只用單一譯名。
2. 學位論文先看摘要與目錄，再決定是否調閱全文。
3. 引用中文文獻時，書目格式全文統一（建議 APA 第七版中文版）。

## 常用來源與用途

| 來源 | 用途 |
| --- | --- |
| Airiti 華藝線上圖書館 | 中文期刊、學位論文，校內多有授權 |
| 臺灣博碩士論文知識加值系統 | 全國博碩士論文摘要與授權全文 |
| 國家圖書館館藏目錄 | 專書、政府出版品、特藏 |
| 臺灣期刊論文索引 | 期刊篇目查詢 |
| 各校圖書館電子資源入口 | 校外 VPN／SSO 連線、館際互借 |

## 檢索查核表

- [ ] 中英文關鍵字各 3–5 組，含同義詞。
- [ ] 年限、文獻類型（期刊／論文／專書）先限定再放寬。
- [ ] 高引用文獻回頭追參考文獻（snowballing）。
- [ ] 引用前確認版本（預印本 vs 正式出版）。
